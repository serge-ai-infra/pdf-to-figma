1 · Import vector

Convert a page first: pdftocairo -svg -f N -l N in.pdf out.svg

2 · Export raster

Exports at dpi/96 — Figma imports SVG as CSS pixels, where 1pt is 4/3px. Pixel size then matches pdftoppm -r DPI exactly, so the diff needs no resampling.

3 · Build from payload

Payload from emitter: components + instances for matched candidates, plain nodes otherwise. Re-running updates existing component masters instead of duplicating them; the build frame itself is cleared and rebuilt every run.

4 · Export built IR

Reads the build frame's tagged nodes back into IR-shaped JSON — points, not pixels — for pdf2figma verify structural. Nothing is sent anywhere; the file downloads locally.

5 · Import geometry donors

From pdf2figma convert donor: cropped, geometry-only SVG for path-kind shapes, dropped into the existing build frame and tagged the same way every other built node is. Run this after Build (panel 3, which clears the frame) and before Export built IR (panel 4) if the donor should show up in the structural diff.

Pick an SVG to begin.
